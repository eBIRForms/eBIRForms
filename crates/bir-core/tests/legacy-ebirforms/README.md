The `IAF_RDO_Copy/` return fixtures are the plaintext of copies first
generated from the synthetic `1601C-062025.official.xml` sample payload with
the official `Encrypt.exe` (v7.9.6.2.1). This repo carries no IAF key, so
they are stored decrypted; a scan reads them as plaintext final copies and
reports a genuinely encrypted copy as an issue.
The fixture values use only test TIN `123456788` and synthetic taxpayer data.
